# Headquarters as Objects

Simple GRF to make all the base set headquarters objects available as 1cc placeable objects, if you wanted to do that for some reason.

Uses [Roadie](https://github.com/mattkimber/roadie) for templating but only because that was the toolchain closest to hand.

I've included the nml source anyway so that you don't need it if you want to hack on this. Might serve as an example of how to use nml procedures with params.
